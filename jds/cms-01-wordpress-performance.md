# WordPress Developer Needed

**Field:** CMS · **Size:** Medium · **Good for:** WordPress builds, performance and Core Web Vitals, hosting and caching layers, ongoing maintenance

---

## Summary

We need a developer to build a custom WordPress site for a client. The project includes creating a responsive design, setting up core site functionality, and ensuring the site is easy to manage. You will work with our team to deliver a polished, user-friendly website that meets the client's needs. Experience with WordPress development and clear communication are important for this role.

This is a part-time, ongoing hourly role. Expect it to run heavier in the first few weeks while we fix current issues, then taper to lighter maintenance.

## What we need help with

- Diagnosing current load speed bottlenecks (frontend + backend)
- Optimizing our Kinsta hosting configuration for WordPress performance
- Improving Core Web Vitals and overall page load times
- Making sure caching, compression, graphics on the page, and code are within best practices
- Ongoing technical maintenance and proactive performance monitoring

## Tools and experience required

- Strong hands-on experience with Kinsta-hosted WordPress sites (or equivalent premium managed WordPress hosting)
- Real server-level performance tuning: comfortable going beyond plugin settings
- Elementor
- WP Rocket (or the judgment to tell us if it's still the right caching layer alongside Kinsta's native caching)
- Rank Math SEO
- Cloudflare (DNS, CDN, security)
- Comfortable auditing and improving an existing setup, not just building new sites from scratch

## What success looks like

- Faster load times across key pages
- Stable performance during traffic spikes
- Clear communication and proactive recommendations
- Reliable ongoing backend support

## Ideal candidate

- Strong English communication
- Proven track record optimizing WordPress sites on premium managed hosting (Kinsta experience is a strong plus)
- Comfortable working directly with server and hosting settings, not just WordPress plugins
- Can clearly explain what they're doing and why
- Available for several hours of overlap with US Eastern business hours for calls and collaboration

---

**Practice note:** you won't have access to the client's site or hosting. For your Phase 4 project:

1. **Build** the custom WordPress site the summary describes, from your own brief: responsive, with core functionality and easy for editors to manage.
2. **Make it realistic before you tune it.** Add enough content, images and plugins (a page builder such as Elementor, an SEO plugin) for it to behave like a real business site.
3. **Measure, tune, measure again.** Record Core Web Vitals and load times for key pages with [PageSpeed Insights](https://pagespeed.web.dev/) before and after each change: caching, compression, images, code, CDN.
4. **Decide the caching layers.** Write down which caching you use (host, plugin, CDN) and why. That is the judgment the JD asks for.

Any WordPress host works. Managed WordPress hosting is closest to the JD; note which one you used.
